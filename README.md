# Machine Learning Experiments

## About
This repository contains Machine Learning experiments and practical work completed during college lab sessions. It includes Jupyter Notebook files (`.ipynb`) containing code, outputs, and visualizations, along with the datasets used for the experiments.

## Contents
- **Jupyter Notebooks (`.ipynb`):** Step-by-step implementations of EDA, preprocessing, data visualization, and supervised ML algorithms.
- **Datasets (`.csv`):** Data files used across the experiments (`iris.csv`, `iris (3).csv`, `heart (8).csv`, `Salary_Data (1).csv`, `diabetes (6).csv`, `diabetes (1).csv`).
- **Experiment Outputs:** Embedded tables, accuracy metrics, and plots generated from executing the notebooks.

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Experiments Included
1. **Experiment 1:** Exploratory Data Analysis (EDA) on the Iris Dataset
2. **Experiment 2:** Data Preprocessing (Missing Value Imputation, Label Encoding & Feature Scaling)
3. **Experiment 3:** Data Visualization (Histograms, Boxplots, Pairplots, Heatmaps & Scatter Plots)
4. **Experiment 4:** Logistic Regression (Heart Disease Classification)
5. **Experiment 5:** Linear Regression (Salary Prediction)
6. **Experiment 6:** K-Nearest Neighbors (KNN) Classifier (Diabetes Prediction)
7. **Experiment 7:** Decision Tree Classifier with Hyperparameter Tuning (Diabetes Prediction)
